New workflow
------------
1. Deploy both files.
2. Open the whatsapp-reader homepage.
3. Click "Preview prospects" FIRST.
4. It scans up to 1,000 recent direct chats but does NOT import anything.
5. Review the returned names/phone numbers/labels.
6. Only if those look like genuine historical property enquiries, click "Import prospects".

--------

  existing_tenant

Prospect imports are marked:
  renter_prospect

The /admin page now displays only renter_prospect records, so the five test
