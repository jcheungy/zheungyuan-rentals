張園 Full Rental CRM v2

WHAT THIS DOES
- Keeps the working WhatsApp/Chromium setup.
- Preserves the existing 8 renter records and message history.
- Expands the same database to classify rental contacts as renter, tenant,
  landlord, agent, other rental contact, unrelated or unknown.
- Imports ALL available messages for recognised rental-labelled chats.
- Adds landlord/agent property extraction.
- Adds saved property-to-renter matches.
- Adds admin sections: Overview, Renters, Landlords, Properties, Agents, Matches.
- Adds paginated GPT conversation reading so the GPT can genuinely read every
  stored message, even when a contact has more than 500 messages.

IMPORT
After Railway deploy:
1. Open the whatsapp-reader homepage.
2. Click "Preview rental CRM chats".
3. Click "Import ALL rental CRM chats + ALL messages".
4. Wait until running=false.

DEFAULT RENTAL LABELS
- To organise viewing
- Viewings -
- Tenants
- Agents
- Landlords / Landlord / Owners / Property owners

Private/unlabelled chats are NOT imported.

If your landlord chats use another WhatsApp label, add the Railway variable:
CRM_EXTRA_LABELS=Your label,Another label

If a landlord chat is currently unlabelled, give it a "Landlords" label in
WhatsApp and rerun the import. This avoids importing unrelated private chats.

properties from landlord/agent conversations, then match available properties
against active renters and relevant historical demand. Continue until complete."

V2.1 — FIND THE UNLABELLED HISTORICAL RENTERS

Why only 8 renters appeared:
The earlier importer selected only chats carrying recognised WhatsApp labels.
Only 8 chats were classified as renter_prospect, so the Renters page correctly
showed 8.

To discover the hundreds of historical enquiries:
1. Deploy reader/server.js from this package.
2. Open the whatsapp-reader homepage.
3. Click "Import ALL direct chats + ALL messages".
4. Wait until discovery status shows running=false.
5. Then ask the GPT:
   "Rebuild the CRM from all imported contacts. Review every contact and every
    message. Classify genuine property enquiries as renter_prospect even if
    they were unlabelled; classify non-rental/private chats as unrelated. Save
    every classification and renter analysis. Continue until complete."
6. Refresh /admin. The renter count will rise only as GPT classifies contacts.

WARNING:
This discovery import intentionally imports all one-to-one chats, including
unlabelled personal chats, because it is the only reliable way to find old
rental enquiries that were never labelled. Groups are excluded.
